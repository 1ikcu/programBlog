一、前提情要：

系统 Ubuntu 20.04，OpenCV 3.4.11，PCL 1.12.1

照着书中的步骤编译 点云拼接的实例：joinMap。但是编译不过，make 后弹出了一连串的报错，类似下图这种：

error: ‘divscalar2’ is not a member of ‘pcl::traits’

error: ‘pcl::traits::HasNoNormal’ has not been declared

error: ‘pcl::traits::HasXY’ has not been declared

error: ‘pcl::traits::HasXYZ’ has not been declared

error: ‘pcl::traits::HasNormal’ has not been declared

error: no match for call to ‘(pcl::getFieldsList(const pcl::PCLPointCloud2&)

error: no matching function for call to ‘isXYZFinite(const pcl::PointXYZ&)

于是我到处搜这些 error，基本都是说 pcl 版本的原因，所以就重新卸载 pcl，又装回来再试，来来回回装了四五次。。中途甚至还以为是OpenCV的问题，也重新装了一次。最后装了 pcl 1.12.1 版本的。
