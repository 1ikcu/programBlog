工具使用

运行参数：

  • image_path: 来自相机传感器的图像文件
  • pcd_path 来自激光雷达传感器的 PCD 文件
  • intrinsic_json: 相机固有参数 JSON 文件
  • extrinsic_json: 传感器间外部参数初始值的JSON文件

使用

README 翻译如下：

标定窗口由左侧控制面板（用于手动标定）和右侧点云投影图像组成。用户可以通过点击面板上的相应按钮或使用键盘输入调整外部参数来检查点云与图像是否对齐。当点云与图像对齐后，标定结束，点击保存按钮保存结果。

Extrinsic Params Keyboard_input Extrinsic Params Keyboard_input
+x degree q -x degree a
+y degree w -y degree s
+z degree e -z degree d
+x trans r -x trans f
+y trans t -y trans g
+z trans y -z trans h
Intrinsic Params Keyboard_input Intrinsic Params Keyboard_input
+ fy i - fy k
+ fx u - fx j

Intensity Color: LiDAR强度记录为激光束的回波强度，部分取决于被激光脉冲击中的物体的反射率。此按钮可将显示模式切换为强度图显示模式。这有助于检查地面车道线是否对齐。

Intensity Color: 消除0.4m深度范围内的重叠激光雷达点。

deg step t step fxfy scale :这三个按钮会随着每次点击或键盘输入而改变调整步骤。

point size: 调整投影图像中激光雷达点的大小。

Reset: 按下按钮重置所有手动调整。

Save Image: 如果按下此按钮，结果（校准图像、外部和内部矩阵）默认存储在运行目录中
