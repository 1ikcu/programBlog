active激活/选中状态

.menu-item

普通状态下的菜单项样式：

  • color: #ccc - 文字颜色为浅灰色
  • text-decoration: none - 移除下划线
  • margin-right: 20px - 右侧留出20像素间距
  • cursor: pointer - 鼠标悬停时显示手指图标

.menu-item.active

激活/选中状态下的菜单项样式：

  • color: #fff !important - 文字变为白色（!important 表示强制应用）
  • border-bottom: 2px solid #fff - 底部添加白色边框作为选中指示
  • font-weight: bold - 文字加粗

内边距（padding）说明

  • padding: 10px 20px; - 上下10px，左右20px
  • padding: 0 15px; - 上下0，左右15px（只增加左右间距）
  • padding-left: 20px; - 只增加左边
  • padding-right: 20px; - 只增加右边
  • padding: 10px 15px 5px 20px; - 上、右、下、左（顺时针）

margin（外边距）与 padding（内边距）的区别

属性 方向 作用 视觉效果
